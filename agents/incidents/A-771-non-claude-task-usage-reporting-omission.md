### A-771 — 2026-11-18 — Non-Claude coordination — mandatory task accounting omitted

- **Severity/status/attribution:** Serious; confirmed recurring coordinator/agent reporting violation of existing `AGENTS.md` requirements; **not** an application or test failure. Some underlying local usage logs may exist unpublished, and not every session can see all quota meters.
- **What failed:** Several recent Mac and Regiurn non-Claude owner-facing task reports omitted required five-hour and weekly remaining balances, explicit start/end timestamps, exact observed model and reasoning/effort, and/or log publication status. Statements such as “local usage row added” did not provide the accountable task summary. The coordinator repeatedly accepted these incomplete reports and required owner reminders.
- **Evidence:** [M1 owner checkpoint](https://github.com/raisinbran/scrb/issues/340#issuecomment-6973787704); [process issue #358](https://github.com/raisinbran/scrb/issues/358); applicable [AGENTS.md](../../AGENTS.md) usage requirement; [12-column log policy](../usage-log/README.md). This evidence supports missing *reporting*, not a claim that exact quotas were always accessible or that no local file was ever created.
- **Impact:** Prevented reliable comparison of task time, effort, shared allowance and handoff accountability. Extra owner interventions and scheduling uncertainty. Actual task-attributable quota/cost and total owner time spent are **unavailable**.
- **Cause:** Missing explicit closeout gate in non-Claude coordination and incomplete per-task owner-facing summaries. Inaccessible balance displays explain unknown readings but do not excuse omitting an explicit “unavailable — reason”.
- **Correction:** Publish the [dated M1/V1 handoff](../../docs/handoffs/2026-11-18-m1-v1-execution-and-reporting-handoff.md) and add a specific compliance gate to [AGENTS.md](../../AGENTS.md). Every subsequent non-Claude task reports model, effort, start/end PT times, 5h/week start/end readings or specific unavailable explanations, resets, overlap, retries, usage-row disposition and incidents. Verify a new row per task; never fabricate quota figures or silently revise old rows.
- **Remaining risk:** Written policy is not proof of compliance. Audit at least two future non-Claude task conclusions, including a desktop task and cloud task if available; report audit evidence in #358. If open/unpublished branches independently reserve A-771, renumber this incident on the later-merging PR before merge, keeping all cross-references aligned.
