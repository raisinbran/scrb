- **Status / attribution:** Confirmed planning/diagnostic error by the reporting agent, not an SRCB product defect. The exact external Windows sandbox root cause remains unconfirmed.

Exact owner time and account usage caused by this error are unavailable; no production code or owner recording was modified by this guidance.

Tracking issue: https://github.com/raisinbran/scrb/issues/327 . Relevant external reports: https://github.com/openai/codex/issues/47555 and https://github.com/openai/codex/issues/51590 .

Future troubleshooting of matching errors should first check documented reports and safe process lifecycle recovery, while avoiding blanket process termination during active sessions.

Do not disable sandbox isolation, reset app data, or alter SRCB code solely on the unproven root-cause hypotheses. The missing capture helper and Windows M1 acceptance remain separate open work.
