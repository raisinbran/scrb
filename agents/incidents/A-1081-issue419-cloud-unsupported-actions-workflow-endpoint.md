### A-1081 — 2026-11-22 — Unsupported GitHub workflow-specific runs endpoint in read-only #419 preflight

- **Event / attribution:** During the cloud-only source verification for the owner-unapproved 130-minute, zero-upload Windows installer run, a read-only GitHub connector `fetch` was called with `/repos/raisinbran/scrb/actions/workflows/windows-installer-single-runner-smoke.yml/runs?per_page=30`. The connector rejected this route with `INVALID_ARGUMENT / HTTP 400` because the endpoint was not permitted by its URL allowlist. The lookup route was an avoidable audit-tool assumption; this was **not** a workflow, Actions or app build/test failure.
- **Impact:** One rejected metadata lookup and minor audit overhead. No hosted job, workflow dispatch/rerun, code, source branch, artifact, user data or private media was touched by the rejected request. No exact usage/credit cost can be isolated from the shared account.
- **Correction:** Used the supported `GET /repos/raisinbran/scrb/actions/runs?per_page=100` repository run collection, filtered that **first page only** for the dedicated workflow, and did not claim the absence of results proved a lifetime no-run guarantee. Independently verified merged #424/#431, source CI, workflow content and issue #419 status; published explicit NO-DISPATCH preflight under [issue #419](https://github.com/raisinbran/scrb/issues/419#issuecomment-7083092814).
- **Prevention:** Use documented connector-supported GitHub URL families rather than assuming arbitrary nested Actions endpoints are allowed; bound claims to returned pages. No code/test or security change is needed.
- **ID:** Selected after current `main` incident register (highest A-1079), all 36 open PR changed-file inventories and available public issue reservations showed no A-1081. Inaccessible unpublished host-local reservations remain **NOT VERIFIED**.
