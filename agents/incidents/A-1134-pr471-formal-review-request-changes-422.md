# A-1134 — 2026-11-24 — GitHub formal-review action mismatch

- **What failed:** During the independent after-green-CI reviews of PRs #471 and #473, the cloud reviewer attempted the GitHub `REQUEST_CHANGES` review action for PR #471 using the connected GitHub identity. GitHub returned HTTP 422 `Review Can not request changes on your own pull request`. This PR is authored using the same connected identity, so that review action is unavailable through the connector. The failure was attributable to choosing an unsupported action for the identity, not to source code.
- **Impact:** One rejected API operation and minor review delay. GitHub created no review from the rejected request; no app/repository code, workflow, release, owner device, recording, or installed data changed.
- **Immediate correction:** Submitted a formal `COMMENT` review containing an explicit **CHANGES REQUIRED** disposition at PR #471 exact head `1f662886a761ff9a9994c7c66f207c4f4c880d1b`, review [#6044873547](https://github.com/raisinbran/scrb/pull/471#pullrequestreview-6044873547). PR #473 was also formally reviewed using COMMENT [#6044878883](https://github.com/raisinbran/scrb/pull/473#pullrequestreview-6044878883). Both were posted **after all three required exact-head CI jobs passed**.
- **Prevention:** For this GitHub connection's own PRs, submit a native formal `COMMENT` with a clear disposition; do not attempt native `REQUEST_CHANGES` or `APPROVE` actions that GitHub prohibits for self-authored PRs. Check head/CI gates before comment submission.
- **Incident ID context:** Main's highest published incident was A-1131; PR #471 carries A-1132, and draft PR #472 contains A-1133. A-1134 was not found by current main search or checked recent PR changed filenames at publication; recheck parallel branches before merge.
