### A-1043 — 2026-11-21 — Cloud M1 merge-queue assessment: oversized connector call batch

- **Attribution / failure:** During the cloud PR readiness/merge-order audit, an initial Code Mode invocation attempted to request main/repository state plus 23 PR snapshots (25 connector actions) in one invocation. The service returned `Code Mode exceeded the maximum number of tool calls`. This was a preventable orchestration error, not a GitHub CI, app, package, or attribution defect.
- **Impact:** One failed read-only orchestration attempt and unnecessary coordination time. No Git ref/PR metadata, source, app, recordings, workflows or devices were modified by that failed call. Account-specific credit impact was not exposed and cannot be estimated.
- **Correction / verification:** Retried the read-only audit in bounded batches of at most ten connected calls each. Verified the current branch/PR heads, applicable exact-head CI and formal review records, restacked PR #402 source blobs and trust boundary, and the outstanding owner/installation gates. Did not rerun successful CI or a hosted installer.
- **Prevention:** Limit each Code Mode invocation to ten connector calls, handle batches and review summaries separately, and distinguish connector call-budget errors from production failures.
- **Reservation check and limitation:** A-1043 was absent on `main` at `9f8c4a1e` and in the changed-file inventories of all 43 then-open PRs; M5/W10/REGIURN unpublished machine-local reservations were not accessible and are not attested. The incident is published only on the draft accounting branch and is not claimed merged.
