### A-665 — 2026-11-16 — Recording detail Copy transcript control added an unnecessary layout row

- **Observed effect:** The user reported that the new Copy transcript button introduced a dedicated padded row above the saved transcript, leaving whitespace despite unused room in the existing Export / folder / delete action toolbar. Source inspection confirmed PR #331 placed the copy button inside `TranscriptTab.tsx` and added a `.copyTranscript` row with vertical padding in `recordings.module.css`.
- **Cause and attribution:** Confirmed UI design-guide compliance oversight in the implementation/review of that change. `docs/design/scribe-design-guide.md` sections 7, 8 and 13 require shared `IconButton`/tooltip controls and new actions in the existing toolbar. No individual-author intent or additional device-specific regression was inferred.
- **Correction:** Relocate the identical full-transcript clipboard behavior to a `CopyTranscriptAction` using the standard overlapping-documents copy icon at the right of the meeting detail's existing action row; remove the standalone row; retain disabled/loading checks and clipboard fallback; add toolbar placement, tooltip and full-copy regression tests.
- **Verification status:** Automated checks and independent UI review pending on the corrective PR. No owner recording was accessed. The proposed change does not alter the transcription/backend contracts.
