### A-902 — 2026-11-19 — Invalid Windows installer path presented as verified/copy-ready; caught only by owner

- **Classification:** CONFIRMED assistant-origin guidance/validation failure; user-detected. No Scribe product defect established.
- **Context:** During W10 A3 normal-user pre-install PowerShell path entry, the assistant supplied a path to the locally built `Scribe Setup 0.1.0.exe` using the incorrect segment `C:\Users\bchen.codex\worktrees\...` instead of `C:\Users\bchen\.codex\worktrees\...`.
- **What failed:** The assistant repeated an invalid, ambiguous filesystem path from previous report context without checking separators or normal-user path existence, and exposed it through a copy control as though ready to paste. **Only the owner spotted the missing backslash**. The assistant did not catch this before sending it; the later corrected path was only a syntax correction, **not independently verified filesystem evidence**.
- **Impact:** A paste at the installer prompt could yield a path-not-found error, a false missing-installer conclusion and avoidable time/credit spent looping on environment troubleshooting. No observed failed execution, permission change, installation, recording, library damage, or data loss is supported; do not infer any.
- **Correction:** Updated user-facing text to `C:\Users\bchen\.codex\worktrees\w10-final-installer-73e899d0\scrb\apps\desktop\release-installer-build-b494ef2a88684e9c95dd5a67690db9f1\Scribe Setup 0.1.0.exe`. **This is a candidate reported path**, not proof of an existing readable file. Future host instructions must validate the exact full string/segments before presenting copy UI; distinguish reported from verified paths; use `Test-Path -LiteralPath` and independent `Get-FileHash` **only in an approved normal non-elevated Windows context**. If path inaccessible under that account, STOP and use an owner-approved ordinary byte-preserving transfer with post-copy hash verification. Never change ACLs, impersonate, elevate, or weaken sandbox/security to recover it.
- **Detection source:** The owner's correction in chat; no independent machine-side verification was performed by the cloud assistant.
- **Public evidence:** [Issue #340 explicit incident disclosure](https://github.com/raisinbran/scrb/issues/340#issuecomment-7033020533); [controlling W10 A3 instructions](https://github.com/raisinbran/scrb/issues/340#issuecomment-7032792205).
- **Publication:** Recorded on provisional cloud coordination branch; **NOT merged to main / NOT independently reviewed**. ID checked against current main, this branch and changed paths of all 28 currently open PRs at time of publication; unknown local reservations must still be checked before merging.
