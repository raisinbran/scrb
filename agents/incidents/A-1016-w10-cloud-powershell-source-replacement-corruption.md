### A-1016 — 2026-11-21 — Cloud — PowerShell source replacement duplicated and truncated scripts

- **Attribution:** Confirmed self-induced source-generation error in the W10 hosted-installer follow-on branch.
- **Effect:** The first cloud string-replacement implementation passed a PowerShell regex containing `$'` through JavaScript `String.replace` as a replacement string, which interprets `$'` as the remaining original text. This duplicated the installer smoke body and truncated SHA-guard expressions in both `scripts/test-win-installer-smoke.ps1` and `scripts/package-win-installer.ps1`. Normal automated CI runs may have started for the intermediate broken commits; these must not be counted as valid candidate results.
- **Detection:** A targeted current-head file read showed `test-win-installer-smoke.ps1` had 43,889 bytes and four occurrences of `function Write-SmokeSummary`, compared with the original 11,032-byte single-body script. The package source showed an incomplete 40-hex SHA expression.
- **Correction:** Rebuilt both files from their independently fetched original sources using a function callback for `String.replace`, preventing replacement-token interpretation; re-read both to confirm complete `$'`-terminated SHA regexes, one smoke summary function, and original safeguards. Final script is 13,425 bytes. No release installer, owner audio or device was accessed.
- **Prevention:** For programmatic edits containing PowerShell dollar signs and regexes, always use replacement callbacks and verify complete generated files before publishing. Await exact-head Windows/macOS CI and an independent source review; do not count intermediate CI.
- **Remaining risk:** The final candidate-aware installer path is not yet exercised with a real binary; #402 is draft. Current main/#396/#402 public incident files showed no A-1016, but unpublished reservations remain outside this cloud view.
