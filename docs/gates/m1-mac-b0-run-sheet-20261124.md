## 3. Producing the remote voices and ground-truth timestamps

All work in `$B0=~/scrb-b0-20261124/` (outside the repo and outside temp; not committed).

1. Render each Remote turn to its own file, no playback: `say -v Samantha -o "$B0/stim/A-<n>.aiff" --data-format=LEI16@16000 "<line>"` for Remote A (en_US, female); `say -v Daniel ...` for Remote B (en_GB, male). `say -o` writes a file and plays nothing. Voices checked present on this Mac: Samantha, Daniel.
2. Per-file duration from `ffprobe -show_entries format=duration`. Check each is <= 7.5 s; otherwise shorten the line before freezing.
3. Compose one 16 kHz mono WAV `remote.wav` with `ffmpeg` (`adelay` + `amix`, or `concat` with generated silence): 2.0 s of silence, a start beep (1 kHz sine, 0.2 s, 0.2 amplitude) ending at file time 2.0 s, remote turn n placed at file time `T(n) = 3.0 + (n-1) x 9 + 0.5` s for Remote slots, silence in You slots, an end beep (same tone) at `3.0 + 30 x 9 + 1.0` s, then 1 s of silence.
4. **Ground truth** for each remote turn is `[T(n), T(n) + duration(n)]` in file time, taken from the composition plan and the per-file `ffprobe` durations. These are exact by construction, not estimated from the recording. For You turns the ground truth is the audio itself: detect the speech onset/offset in the saved microphone track (energy envelope above 3x the noise floor, merged within 0.4 s) and match the 10 detected spans to the 10 You slots by order. Words come from the script text, so each turn's reference word list is known.
5. File time to saved-track time: `d = (onset of start beep in the saved meeting track) - 2.0 s`, in the helper's chunk timebase (`chunks.log` `startNs` plus in-chunk offset). Predicted track time of any remote event = file time + d. Tolerances use only this `d`, so the unknown delay between starting `afplay` and the helper's first sample cancels.
6. Remote turns 2, 3, 5, 6, ... are never played simultaneously with a You turn; the 2 s floor of silence per slot keeps the cases "clean, non-overlapping".

## 8. Abort conditions

Stop, write down what happened, do not retry unless a cell is still unscored and the cause was a fixable setup error (owner decides):

- Install: any hash mismatch, `codesign` failure, unexpected password prompt, or rollback rehearsal not returning the backup hash. Roll back at once.
- Launch: crash on start or a second crash on the same step with no new evidence (second identical failure rule). Keep the new crash report; roll back.
- Library: any sign the app opened the owner's library or its file count or `index.sqlite` mtime changed.
- Permissions: microphone or System Audio Recording refused. Owner decision; no OS security changes.
- Preflight: meeting track silent while speakers are muted. Stop and report; do not unmute without the owner's yes.
- Run: a recording stops early, disk below 5 GB free, the machine sleeps, or the clock passes 65 minutes from the first step. Do not restart a running recording.
- Final pass not done 10 minutes after stop: record state, leave app running, score what exists.
- Owner not available for the spoken lines at the agreed time: postpone; nothing is installed until the owner is present (install is cheap to roll back but the replacement app must not sit unvalidated).
