## 3. Remote voices, stimulus and ground truth

**Step 0, before any file is written: create the run directory.** `export B0=~/scrb-b0-20261127; scripts/b0-fresh-b0.sh create` makes `$B0` with a plain `mkdir` (it fails if the path already exists, including a dangling symlink), writes the marker `.b0-run`, and refuses a path that overlaps `~/Documents/Meeting Scribe`, `~/Library/Application Support/Scribe`, `/Applications` or the target app. Every later script (`b0-mac-swap.sh` backup, swap and rollback in production mode too; `b0-mac-isolated-launch.sh` prepare, launch and evidence) re-checks that `$B0` is this non-symlink, marked, disjoint directory before its first write, refuses to write over any existing or symlinked destination, and accepts evidence labels matching `^[A-Za-z0-9_][A-Za-z0-9._-]*$` only. An existing or reused `$B0` is refused: pick a new dated name. All work is in `B0` (outside the repo and outside the temp root; not committed). `FFMPEG=<repo>/packages/transcription/.bin/ffmpeg`.

1. Render each A and B turn to its own file, no playback: `say -v Samantha -o "$B0/stim/A-<k>.aiff" --data-format=LEI16@16000 "<line>"` for A (en_US female) and `say -v Daniel ...` for B (en_GB male). `say -o` writes a file and plays nothing.
2. Check each duration with `ffprobe -show_entries format=duration`; every turn must be at most 7.5 s, else stop and tell the planner (the script may not be edited).
3. Compose one 16 kHz mono `remote.wav`: a start beep (1 kHz sine, 0.2 s, amplitude 0.2) at **1.8 to 2.0 s**; remote turn in slot `k` placed at `T(k) = 3.5 + (k - 1) x 9` s (Y slots silent); an end beep (same tone) at **274.0 s**; 1 s of silence after. The first remote speech is slot 2 at **12.5 s**.
4. Ground truth for A and B turns: `[T(k), T(k) + duration]` by construction. For Y turns: speech spans detected in the saved mic track (energy above 3x the noise floor, merged within 0.4 s), matched to the 10 Y slots by order. Reference words come from section 2.
5. File time to saved-track time: `d = (start-beep onset in the saved meeting track) - 1.8 s` (from `b0-track-sync.mjs --list`). Predicted track time of a remote event is file time + `d`; the unknown `afplay` start delay cancels.

### Isolated profile and library (fail closed, no fallback)

`scripts/b0-mac-isolated-launch.sh prepare` creates the profile and the library under the **real OS temp root** (`node -p "require('fs').realpathSync(require('os').tmpdir())"`), writes `library-location.json` with `{"root": "<library>"}` (key `root`), and records paths in `$B0/run.env`. `launch` runs `open -n /Applications/Scribe.app --args --user-data-dir=<profile> --scrb-isolated-test-profile`. Both flags are required: `main.ts` (about line 387) only runs the isolation check when `--scrb-isolated-test-profile` is present, and `validateIsolatedTestProfile` (`isolated-test-profile.ts`) then needs `--user-data-dir`, a profile and a library inside the temp root, the pointer a regular non-symlink file with an absolute `root`, profile and library separate, and the library not the default `Documents/Meeting Scribe`. Any rejection makes the app log the reason and `app.exit(1)`. The real validator was run against a prepared throwaway layout and accepted it.

**Location is seeded, never clicked (owner decision 2026-11-26).** The packaged app ignores `SCRB_DEV_AUTO_LOCATION`, so before the real launch the agent saves a fictional US state into the temporary library only, in the shape the settings handler uses (observed in an earlier isolated run: key `app.settings`, value `{"location":{"country":"US","usState":"AL"}}`, table `settings(key, value)` in `$LIB/index.sqlite`). Order: (1) `prepare`; (2) first pass with the same flags by hand, `open -n "$CAND" --args --user-data-dir="$PROFILE" --scrb-isolated-test-profile`, wait until `$LIB/index.sqlite` exists, then stop only the process whose command line has `--user-data-dir=$PROFILE`; the dialog is neither clicked nor automated; (3) `sqlite3 "$LIB/index.sqlite" "insert into settings(key,value) values('app.settings','{\"location\":{\"country\":\"US\",\"usState\":\"AL\"}}') on conflict(key) do update set value=excluded.value"` and read it back; (4) `launch` as below. Use only `$LIB` from `run.env`, never another path. If the launch screen still shows the dialog, stop and report (it is the remembering question, not a run-sheet failure to retry). The owner's `~/Library/Application Support/Scribe` and `~/Documents/Meeting Scribe` are never read or written.

**If `launch` prints STOP within 30 s**, read the newest `$LIB/logs/scrb-*.log` and `pgrep -f -- "--user-data-dir=$PROFILE"` once: a first launch of a new ad-hoc signature can take longer than the script's check (2026-11-25: `library-opened` logged, the 30 s check failed, one manual `open -n` then held the library). If the log shows `library-opened` and a process exists, one manual relaunch plus `lsof -p <pid> | grep -F "$LIB/"` and the same no-owner-library check counts as new evidence; a second failure with no new evidence stops the run.

`launch` then **asserts before anything is navigated or recorded**: a live `Scribe` process holds `index.sqlite` or other files under the intended library (`lsof`), none under `~/Documents/Meeting Scribe`; otherwise it closes the app and exits non-zero within 30 s. The agent also reads Settings on screen: the storage location must equal the printed library path exactly. **Any mismatch, rejection or timeout aborts the run: do not retry with another path, do not use the default library.** Retained evidence (copies, hashes, `remote.wav`, video, backups) lives in `$B0`, outside the temp root; run `scripts/b0-mac-isolated-launch.sh evidence <label>` right after the recording stops, after the final pass, and after the restart check, because the temp folder can be cleaned by macOS.

### Install steps

1. Owner confirms present. `pgrep -x Scribe` prints nothing (script checks too).
2. Candidate: `scripts/b0-mac-swap.sh fingerprint "$CAND"` must print both expected digests; `codesign --verify --deep --strict "$CAND"`; `defaults read "$CAND/Contents/Info.plist" CFBundleIdentifier` = `com.raisinbran.scribe`. The swap script re-checks all of this and stops (`exit 1`) on any mismatch.
3. Library baseline, read only: `find ~/"Documents/Meeting Scribe" -type f | wc -l`; `stat -f '%z %m' ~/"Documents/Meeting Scribe/index.sqlite"`; same for `~/Library/Application Support/Scribe/models`. The owner's library is never opened during B0.
4. `scripts/b0-mac-swap.sh backup`: refuses to overwrite, fingerprints the live app, `ditto`s it to `$B0/Scribe.app.backup`, fingerprints the copy, requires both fingerprints identical to each other and to the live app again, and only then writes `$B0/backup.sha` (`files=<64-hex>` and `links=<64-hex>` lines; parsed by field name, not by position). It also refuses a different volume for `$B0` and `/Applications` (`stat -f %d`), because the later moves are renames.
5. **Rollback rehearsal on a throwaway copy, never the real app** (about 2 minutes): make `REH=$(mktemp -d "$(node -p "require('fs').realpathSync(require('os').tmpdir())")/scrb-b0-rehearsal-XXXXXX")` (the guard needs the temp root), `mkdir "$REH/Applications" "$REH/b0"`, `touch "$REH/.b0-rehearsal-root"`, copy the backup to `$REH/Applications/Scribe.app`; run the same script with `B0_TEST_MODE=1 B0_REHEARSAL_ROOT=$REH APPS=$REH/Applications B0=$REH/b0` for `backup`, `swap` and `rollback`, and once with `B0_TEST_FAIL_AFTER_MOVE=1` to exercise the automatic rollback. Test mode skips only `codesign` and the running-app check. It refuses to run unless the canonical rehearsal root is under the canonical OS temp root (and not `/Applications`), holds the regular marker file, and contains **both** the canonical `APPS` and the canonical `B0`; symlinks are resolved first, so an alias or an unrelated temp tree is refused. Production mode has no such switch and keeps every gate. This guard is unit tested with fake directories only (`scripts/b0-mac-swap.test.mjs`). Continue only if every rehearsal result matches.
6. `scripts/b0-mac-swap.sh swap`: stage `ditto "$CAND" /Applications/Scribe.new.app`; require staged fingerprint = candidate and `codesign` OK; `mv` live to `$B0/Scribe.app.replaced`; `mv` new to live; require installed fingerprint = candidate and `codesign` OK. Each `mv` is an atomic rename on one volume; the pair is not, so an `EXIT` trap covers the window. **What the trap is designed to do, and what was tested:** on a shell-level failure after the first rename (ditto, hash, codesign, a failed `mv`, a `set -e` exit) it restores the previous app and requires its fingerprint to equal `backup.sha`; if the restore fails it says so and names `$B0/Scribe.app.backup`. Only an injected script failure was exercised on fake apps; behaviour on Ctrl-C, SIGTERM or SIGHUP is not proven. **Not covered:** SIGKILL, a crash of the shell, power loss or a reboot between the two renames run no trap, and the app can then be missing or be the candidate. **Fallback:** the manual command `scripts/b0-mac-swap.sh rollback` (restores `$B0/Scribe.app.replaced` if present), else `ditto "$B0/Scribe.app.backup" /Applications/Scribe.app` after moving any partial app aside, then compare `fingerprint` with `backup.sha`; check `/Applications` for `Scribe.app` and `Scribe.new.app` after any interruption. Nothing uses `rm`.
7. **Rollback at any time** (failed launch, abort rule): quit the app, `scripts/b0-mac-swap.sh rollback`; it moves the candidate to `$B0/Scribe.app.rc.<pid>`, restores `Scribe.app.replaced`, and exits non-zero unless the restored fingerprint equals `backup.sha`. The library is never moved or written by install or rollback.

Tested only on throwaway fake apps (paths with spaces, an apostrophe and a newline, a symlink): backup, swap, rollback, a wrong expected digest (stops, live app untouched), an injected failure after the second rename (automatic rollback, fingerprint verified) and a missing `Scribe.app.replaced` (loud non-zero). Not run against `/Applications`.

## 7. Cell method and PASS/FAIL/NOT VERIFIED rules (Mac column; Windows out of scope)

**Rule for all cells:** PASS needs every sub-limit met with valid evidence. FAIL needs valid stimulus and evidence plus at least one limit missed. **Any measurement that cannot be made (tool error, beeps not heard, earcup silent (cell 4), helper exit 2, route invalid, run aborted, time cap) is NOT VERIFIED with the precise reason. It is never PASS and never a product FAIL.** Limits are exactly those the owner accepted; the definitions below only say how each is measured.

**Cell 1: two separate synchronized tracks.**

- Run `node scripts/b0-track-sync.mjs "$FFMPEG" <audio folder>` (both tracks decoded from the sealed `chunks.json` timebase (`chunks.log` only if the meeting is unsealed); Goertzel 1 kHz detector, tone runs of 120 to 400 ms). It takes the **start beep (about 2 s) and end beep (about 274 s)** in each track and reports `startOffsetMs`, `endOffsetMs` (mic minus meeting) and `driftMs = endOffsetMs - startOffsetMs`. Verdict: PASS if both offsets are within **250 ms** and `|driftMs|` is within **50 ms**; FAIL if both beeps are found in both tracks, their first-to-last spacing is within 2 s of 272.2 s in each track, and a limit is missed; **NOT VERIFIED (exit 2) if a beep is missing in either track or the spacing is implausible.** (Unit tested with synthetic tracks: pass, 80 ms drift fail, 400 ms offset fail, missing beep not verified, implausible spacing not verified, click and 2 kHz tone ignored.)
- Also: each remote onset within 250 ms of `T(k) + d`; You spans only in the mic track and remote speech only in the meeting track (other-track energy outside the beep windows below 10% of speech level); no gap between consecutive `chunks.json` chunks above 100 ms and no meeting-track silence run longer than the longest scripted silence; no clipped (full-scale) or missing scripted turn.
- PASS: all of the above. FAIL: any limit missed with valid evidence. NOT VERIFIED: as the rule above, or beeps declined.

**Cell 2: live text, three voices.** Screen video and window text reads. One global one-to-one mapping from live labels to Y/A/B (the 3x3 permutation with the most correct clean turns), written to `$B0/mapping-live.json` before any per-voice figure and then frozen; no final-pass rescue of live scoring. PASS: median live delay (turn end to first visible matching live text) **at most 3.0 s**; **at least 29 of 30** turns within **6.0 s** (missing or late count as failures; denominator 30, no exclusions); **at least 8/10 recognizable and correctly attributed live turns for each remote voice**. FAIL: valid evidence and a limit missed. NOT VERIFIED: live text not observable, or a turn lost to an operator error (no retry): that voice is NOT VERIFIED. "Recognizable" means at least 60% of the phrase's words appear in order within the turn's window; this definition is declared before the run and is not a threshold change.

**Cell 3: final text and distinct voices.** From `transcript.json` after the final pass: exactly three distinct speaker ids; one frozen global mapping (`$B0/mapping-final.json`); **30/30 turns recognizable**; **at least 9/10 correctly recognizable and attributed turns for each of Y, A and B**; A and B not merged; no fabricated scripted turn. Report the 3x3 table and word omission/extra counts. FAIL: final pass fails or limits missed with valid evidence. NOT VERIFIED: final pass blocked by an environment problem outside the app (power, disk), not retried.

**Cell 4: audible, measured seek** (headphones needed; earcup against the mic, speakers muted). Targets Y01 "copper", A05 "suitcase", B10 "glasses". The progress indicator alone is never evidence.

## 8. Abort conditions

Stop, write down what happened, do not retry unless a cell is still unscored and the cause was a fixable setup error (owner decides):

- Install: any fingerprint mismatch, `codesign` failure, unexpected password prompt, or rehearsal not returning the backup fingerprint. The swap script rolls back automatically; verify with its output.
- Isolation: `launch` assertion failed, the app exited on the isolated profile, or Settings shows any other location. No fallback path.
- Launch: crash on start, or a second identical failure with no new evidence. Keep the crash report; roll back.
- Library: any sign the app opened the owner's library, or its file count or `index.sqlite` mtime changed.
- Permissions: microphone or System Audio Recording refused. Owner decision; no OS security changes.
- Preflight: no remote speech in the meeting track with speakers muted. Stop and report; do not unmute without the owner's yes.
- Run: a recording stops early, disk below 5 GB free, the machine sleeps, or the clock reaches **60 minutes** from the first step (the owner-approved total; there is no grace period). Do not restart a running recording; cells not yet scored are NOT VERIFIED (time cap).
- Final pass not done 10 minutes after stop: record state, leave the app running, score what exists.
- Owner not available for the spoken lines at the agreed time: postpone; nothing is installed until the owner is present.
