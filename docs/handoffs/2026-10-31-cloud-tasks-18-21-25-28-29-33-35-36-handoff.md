## Validation and limitations

- GitHub Actions on this draft PR executes macOS and Windows `npm ci`, changed-TypeScript Prettier, typecheck, ESLint, summary build, Vitest, boundaries, desktop build, and Playwright smoke. At the time of handoff authoring, final code checks were still running in [run #41254837800](https://github.com/raisinbran/scrb/actions/runs/41254837800). **Do not infer a green result unless the run shows `success`**. Previous runs failed formatting or compilation before tests; these were addressed by later commits.
- Git clone/checkout and any `npm` commands **were not run locally**: the execution container could not resolve `github.com`. The GitHub connector was used to read exact source and push commits to the QA branch. No owner device or real meeting data was used.
- **Not run:** installed Electron file picker, actual FFmpeg imports/decoding/transcription, PDF printing or real DOCX/PDF parity, microphone or source switching, installed model downloads/generation, native macOS/Windows permission tests, GPU/workload/memory benchmarks, hardware speaker identification, voice profiles, physical file locks, accessibility screen readers and 200% zoom, precise license validation, source-offer review, installed-app network instrumenting and release installers.
- Draft PR #8 is for **Claude's QA**. The master agent should distinguish genuine blocking defects from incomplete product work, run targeted fixtures/native tests, keep the branch unmerged until owner approval, and avoid plan/QA bloat.
