## Five cross-cutting V1 blockers

1. **Packaging/model distribution:** `scripts/package-mac.sh` builds an ad-hoc signed Mac `.app` and installs models separately; owner's later personal-use plan supersedes the original generic DMG expectation. Main Windows slice 2 stages **six non-capture tools**; model handover #346 remains an open PR, and native capture/NSIS/clean-PC recording acceptance are separate. Initial downloader exists but physical full installed offline flow remains **NOT VERIFIED**. Don't offer slice-2 `Scribe.exe` as a recording app.
2. **Input presets:** [#335](https://github.com/raisinbran/scrb/issues/335), [#338](https://github.com/raisinbran/scrb/issues/338), draft [#337](https://github.com/raisinbran/scrb/pull/337). Saving flags is not implementing suppression/AEC/AGC. Preserve raw original and `<=0.5 dB` unintended output-level limit; Mac voice-processing spike attenuated the *meeting tap* ~9 dB, **not proven physical speaker level**. No default enablement without owner-approved risky-change plan and evidence.
3. **Safe shutdown/background final pass:** [#49](https://github.com/raisinbran/scrb/issues/49). `Sidebar.tsx` already has an activity dot via `useAnyProcessing`, but `TitleBar.tsx` lacks an explicit cross-tab processing message. `quit.ts` holds async cleanup for up to 15 seconds; `FinalPassQueue.shutdown()` aborts and resume on later launch **restarts**, not checkpoint-resumes. **No close/quit confirmation on main.** Separate risky lifecycle plan/approval before quit interception.
4. **Speaker-profile reliability:** `startProfileMatching` uses a verified model and conservative 0.6 auto threshold but matches only previously seeded eligible named profiles; `voiceProfiles.create/grow` have no production callers. Missing learning and persisted suggestions is a **real implementation gap**, not just insufficient evidence. Draft [voice growth plan](../plans/voice-profile-growth.md) proposes contributions, opt-in, reversible deletion/undo and privacy safeguards; do not split away those safeguards or infer reliability from speaker counts.
5. **Gate 8:** Main Mac endurance record lasted **7:29:58.604**, shorter than 8 h, and reported 4.3469 s mic gaps and worst 4-hour drift 65.81 ms vs 50 ms limit; Windows endurance acceptance not established. #325 fixed verifier mixed-rate logic but not the actual evidence. Draft [#337 Gate 8 input-settings checklist](https://github.com/raisinbran/scrb/blob/rosmont/v1-input-settings-gate8-20261116/docs/gates/gate-8-input-settings-acceptance.md) adds 15 unrun controls checks. **Gate 8 FAIL / NOT ACCEPTED**, and no long rerun is authorized.
