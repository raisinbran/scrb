## Owner decision

If a crash happens before the migration commits, SQLite rolls the live index back to the old version, unchanged. D1's fix leaves this blocked, because plan case B lists a crash as blocked. Recommendation: after rollback, if the live index matches the verified snapshot, treat it like case A, remove the snapshot and upgrade again. This restores nothing, and otherwise a crash during an upgrade leaves the library closed for good.
