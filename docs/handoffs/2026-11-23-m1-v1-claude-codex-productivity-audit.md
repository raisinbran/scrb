**Assessment date:** 2026-11-23, Pacific time. **Measured engineering window:** 2026-10-27 through 2026-11-22 inclusive (the last complete day of the pinned main history). **Pinned main:** [b75bd7f42ec3540751baa31ae59bf0c9485bb059](https://github.com/raisinbran/scrb/commit/b75bd7f42ec3540751baa31ae59bf0c9485bb059). **From:** independent cloud GitHub/source investigation. **To:** owner, M1 delivery coordinator, Mac M5 executor, Windows BCHEN-W10 executor, and separate CI/review agents.

**Disposition:** M1 **NOT ACCEPTED**; V1 **NOT ACCEPTED**; three of nine whole-project gates approved; macOS Gate 3 separately owner-approved; Windows Gate 3 and remaining gates not fully approved. The installed-candidate evidence matrices report **M1 0/15** and **V1 0/28** verified cells. The zeroes mean **not verified**, not that 43 tests failed. No final cross-platform release-candidate SHA has been selected.

**Bottom line:** The owner's observation of deteriorating throughput after November 15 is supported by dated GitHub activity and CI results. In November 8–15 (Claude-access window), 458 commits on today's main history, 229 direct-to-main PR merges, and 859/1,031 successful CI runs were observed. The latter period delivered legitimate source and packaging-safety improvements, **but no newly accepted M1 step on a final installed candidate, no V1 installed acceptance, and no new full gate**. Recurring execution/permission failures, avoidable test mistakes, re-work between agents, and coordinating overhead materially displaced end-to-end delivery.

## 1. Evidence and limits of attribution

The owner identified two **Claude-access** windows, **October 27–November 3** and **November 8–15**, and two **ChatGPT/Codex-only** windows, **November 4–7** and **November 16–22**. The labels below are **calendar access regimes**, not assertions that Claude personally authored every changed line or operated every machine on those days. The GitHub author is typically the owner's account; its commit metadata cannot identify the AI/model that performed the work. For example, the [Mac Gate 3 record](../gates/gate-3-macos.md) explicitly credits the physical runs to Codex and a later evidence review to Claude. Do not attribute that gate solely to either tool.

All calendar-day grouping uses GitHub timestamps converted to **America/Los_Angeles** (including the November 1 DST transition). The frozen main commit-history query was paginated to completion: **1,112 unique reachable commits** (11 pages of 100, page 12 with 12, page 13 empty). PR counts were calculated from **433 fetched pull requests**, using merge timestamps and direct base **main**. CI figures come from the repository Actions run collection, selecting completed successful/failed runs whose workflow path is **.github/workflows/ci.yml**; each workflow run contributes **one latest observed conclusion**, even if a failed job was retried. CI figures are **not first-attempt success rates**.

**Critical caveats:** Commit timestamps are not the date a branch entered main, stacked/non-squash history greatly inflates early commit totals, merges may admit earlier-dated commits, PRs differ in size, and tasks vary in complexity. PR titles are only an approximate code-versus-documentation classifier. No reliable, comparable task-hours, task-attempt denominator, QA-defect severity denominator, or Claude-vs-Codex device execution log is available; **an actual task success percentage or causal per-model productivity claim would be fabricated**. CI run success and merge throughput are measurable proxies, not substitutes for user delivery.

## 4. Why the Nov 16–22 delivery rate stalled

**Observed operational failures, separate from app quality:**

1. **Codex execution capability mismatches and repeated host-context failures.** BCHEN-W10 Git CLI configuration permission denied; sandboxed Git metadata writes denied despite ordinary file reads/writes; constrained CUA GUI control stalled; some cloud GitHub sessions can inspect or rerun Actions but **cannot create a new workflow dispatch**. The proper outcome should have been a single bounded capability assessment and handoff, not repeated loops. See [Nov 18 blocker handoff](2026-11-18-codex-blockers-m1-v1-installed-delivery-handoff.md), [M1 Mac crash issue #357](https://github.com/raisinbran/scrb/issues/357), [installer issue #419](https://github.com/raisinbran/scrb/issues/419).
2. **Mac Electron startup abort before any Scribe code.** The current isolated package built from **b75bd7f42** passed static checks; one bounded direct launch exited **134/SIGABRT** during HIServices/AppKit application registration, before UI/backend/library creation. Existing [Electron issue #52815](https://github.com/electron/electron/issues/52815) and [Codex issue #30043](https://github.com/openai/codex/issues/30043) provide a strong sandbox/Mach-service analogy, **not confirmed on M5**. No repeated launch is warranted without comparison to existing crash and unified logs. Preserve production app and rollback; do not infer recording failure from this startup crash. [Read-only task #340](https://github.com/raisinbran/scrb/issues/340#issuecomment-7088387144).
3. **Windows installer workflow was authorized but skipped before runner allocation.** [Run #45086217075](https://github.com/raisinbran/scrb/actions/runs/45086217075) has correct actor, source and first-attempt metadata; the specific false job-level conjunct is not shown. Do **not** assert an unchecked opt-in as a proven cause. [Diagnostic PR #454](https://github.com/raisinbran/scrb/pull/454) adds nonsecret run-name inputs without relaxing ten authorization checks. It then suffered **basic avoidable ESLint and CRLF-sensitive test assertion failures** before reaching a corrected head, **3d7686cafb2eb945aae56dad1eeec5e571818b67**. Latest checked [application CI #45126047442](https://github.com/raisinbran/scrb/actions/runs/45126047442) and [source checks #45126047444](https://github.com/raisinbran/scrb/actions/runs/45126047444) both **PASS**. **No formal review or merge as of this audit**. Run #45086217075 consumed its distinct one-dispatch authorization; another genuine 130-minute attempt needs a new exact-SHA owner decision after guard diagnosis. Do not use Re-run.
4. **Recurrent unrelated flaky or misleading CI faults.** [Issue #380](https://github.com/raisinbran/scrb/issues/380) tracks intermittent Windows summary retention deletion result in an unchanged test; a successful targeted retry for [safe-quit PR #444](https://github.com/raisinbran/scrb/pull/444) cleared exact-head CI, **not** the root cause. Separate [PR #452](https://github.com/raisinbran/scrb/pull/452) introduces deterministic barriers and sanitized phase/residue diagnostics. Keep it separately reviewed; do not misattribute the old failed assertion to #444.
5. **Cross-session continuity and administration overhead.** Historic instructions became stale, agents repeated preflights or rediscovered blocked operations, and incident-number collisions/usage accounting spawned multiple docs PRs. The requirement to preserve accounting is valid, but its execution must be batched and kept off M1's runtime critical path. [Three-machine Nov 15 recovery audit](three-machine-recovery-audit-20261115.md) found **163 Mac worktrees (21 dirty)** and **13 BCHEN-W10 worktrees (two dirty)**—strong indicators of environment/worktree coordination cost, not direct app defects. [Nov 18 handoff](2026-11-18-codex-blockers-m1-v1-installed-delivery-handoff.md) explicitly reported the same delivery gap.

**Attribution judgment:** The measured decrease is real at the workflow level. The recurring CI syntax/CRLF mistakes were avoidable agent errors; unimplemented connector capabilities and restricted host permissions are genuine environment limitations; the Mac LaunchServices hypothesis and intermittent retention root cause are **not yet proven**. Neither blaming the Scribe product nor declaring every fault a Codex defect is supported. The major management failure was letting these repeat without a one-hypothesis stop rule, while no safe known-build installed M1 test completed.

These outputs explain where engineering effort went. They **do not excuse** the lack of an accepted deliverable.
