# Handoff notes

One file per note, closed when the receiving side merges. Use a handoff note when the UI needs something the contract lacks, or a backend change needs UI work. Never work around the contract.

```markdown
- [ ] From and to
- [ ] What changed or is needed, in one or two sentences
- [ ] Contract items affected
- [ ] Screens or backend areas affected
- [ ] How to test it
```
