Worst gaps, by owner impact:

1. **Pointer and text selection (F13, F14), PARTIAL / NOT DONE.** On main the Live transcript `.canvas` is `cursor: text; user-select: none` (`apps/desktop/src/ui/screens/live/TranscriptView.module.css:84-89`): an I-beam over the whole canvas, including gaps and row margins, and text cannot be selected or copied. No `contextmenu` handler exists anywhere in `ui/`, so there is no right-click Copy or "Correct text". The only other `cursor: text` is the speaker rename button (`recordings.module.css:539`), the wrong place. Open PR #210 claims to fix it; it is not merged.
2. **Live word edit error and stuck purple highlight (F11, F12), NOT DONE on main.** Nothing in `TranscriptView.tsx`, `CorrectionEditor.tsx` or `TranscriptTab.tsx` clears the selection (`removeAllRanges` and `getSelection().empty` are absent). Also in #210.
3. **Settings as a fading overlay (F21b), NOT DONE.** Settings is a full screen (`App.tsx:56`, `AppShell.tsx` renders `screenId`), not an overlay; no fade, no click-outside.
4. **Model dropdown, "(Recommended)" and hardware warning (H22), and "Re-run computer benchmark" (H24), NOT DONE.** No UI and no contract support (`packages/contracts` has no benchmark or recommendation field). Both need owner contract approval; the design guide §13.8 records them as parked.
5. **Warnings as centred popup banners (H4), PARTIAL.** `PopupLayer` is used only in the meeting detail and Summary tab. Live alerts are a custom left-anchored float (`LiveScreen.module.css:226-250`), and the import voice-profile notice and Settings error line remain rows.
6. **Speaker separation (F16), PARTIAL.** The final pass separates five remote voices on the long recording but not on R2 (`docs/handoffs/2026-11-14-speaker-and-followalong-diagnosis.md`); live two-remote grouping is unproven (V04) and a final mislabel (E14) is open (#340).
7. **Preset-locked tooltip wording (H23), PARTIAL.** The owner asked for "Set by Voice Isolation/Studio"; the code says "Saved under Studio; processing unavailable" (`AudioSection.tsx:94`), a deliberate honesty change, because presets do not yet change audio (V13, #335).

## Recommended smallest fixes (at most five tasks)

1. **Pointer, selection, context menu, live edit (F11-F14).** Review and land #210 (or re-cut it): drop `cursor:text` and `user-select:none` from the whole `.canvas`, set them only on word spans; clear the selection when the editor closes; add the Copy and "Correct text" menu. Test with a jsdom assertion on the cursor class and on selection clearing. High owner impact.
2. **Settings overlay (F21b).** Render Settings as a Dialog-style overlay over the current screen with the shared fade, close on outside click and Escape. UI only; recording is already unaffected.
3. **Warnings through PopupBanner (H4).** Move Live alerts, the import voice-profile notice and the Settings error line onto `PopupLayer`/`PopupBanner`, centred over their panel. UI only.
4. **Contract-gated Settings items (H22, H24, H23).** Write the contract proposal for a model list with a recommended flag and a re-run benchmark action, get owner approval, then add the dropdown and button; align the preset tooltip wording with the owner's "Set by <preset>" once presets work (V13).
5. **Summaries and speaker follow-ups (H28, H31, F16).** Decide whether summaries are generated automatically after the final pass and wire it; add track audio preview for "Split a speaker"; finish E14 (#340). Each is its own small slice.
