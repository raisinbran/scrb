# Scribe icon concepts

The shipped icon (concept A, speech bubble) is a placeholder so builds have an icon, pending the owner's decision on the final design. The three concepts stay here, and `node scripts/make-icons.mjs [bubble|wave|nib]` regenerates the icon set from any of them. Open `preview.html` to compare them.

Seven candidate designs are in `scribe-<name>.svg` (each with a `-win` version); `preview-all-options.html` shows them at large size and at 32 and 64 px, on light and dark. Each glyph is scaled to about 78% of the tile width. `r1a`: red recording dot then sound bars. `r5b`: red dot then a wave that flattens. `r5c r5d r5e`: red dot then a smooth voice waveform (rounded amplitude envelope, bars, or a symmetric swell) that settles toward a line. `h3sa h3sb`: one stroke, a wave settling into a looping word. The dot is `#ff4d4d` with a white ring so it keeps 3:1 contrast against the tile; colours stay in the icon SVGs. They are candidates only; none is shipped. Regenerate the icon set from one with `node scripts/make-icons.mjs r5e` (or any other name above).
