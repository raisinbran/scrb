# Scribe icon concepts

The shipped icon (concept A, speech bubble) is a placeholder so builds have an icon, pending the owner's decision on the final design. The three concepts stay here, and `node scripts/make-icons.mjs [bubble|wave|nib]` regenerates the icon set from any of them. Open `preview.html` to compare them.

Options H1, H2 and J2 (`scribe-waveslide`, `scribe-wavestack`, `scribe-arcsnib`, each with a `-win` version; preview in `preview-refined-options.html`) are refined candidates: white glyph on the indigo tile, a fountain-pen nib that touches the line it writes. They are candidates only; none is shipped. Regenerate the icon set from one with `node scripts/make-icons.mjs waveslide` (or `wavestack`, `arcsnib`).
