# Scribe icon concepts

The shipped icon (concept A, speech bubble) is a placeholder so builds have an icon, pending the owner's decision on the final design. The three concepts stay here, and `node scripts/make-icons.mjs [bubble|wave|nib]` regenerates the icon set from any of them. Open `preview.html` to compare them.

Four designs, each with an inverted version, are in `scribe-<name>.svg` (each with a `-win` version); `preview-all-options.html` and `preview-all-P.png` show them at large size and at 32 and 64 px, on light and dark. Each glyph is about 78% of the tile width. `r1a`: red recording dot then sound bars. `r5c`: red dot then a smooth voice waveform fading into a line. `h3sb`: one stroke, a wave settling into a loop. `h3sd`: a swelling voice wave ending in a small loop. Names ending `i` are inverted: white tile, indigo glyph. Owner decision: the app default is `r1ai`; the rest are meant to be selectable in Settings under the theme selection. The dot is `#ff4d4d` with a white ring (indigo on the inverted tiles) so it keeps 3:1 contrast; colours stay in the icon SVGs. The shipped icon is still the speech-bubble placeholder until `r1ai` is wired in. Regenerate the icon set from one with `node scripts/make-icons.mjs r1ai` (or any other name above).
