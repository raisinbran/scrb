# Scribe icon concepts

The shipped icon (concept A, speech bubble) is a placeholder so builds have an icon, pending the owner's decision on the final design. The three concepts stay here, and `node scripts/make-icons.mjs [bubble|wave|nib]` regenerates the icon set from any of them. Open `preview.html` to compare them.

Ten candidate designs are in `scribe-<name>.svg` (each with a `-win` version); `preview-all-options.html` shows them at large size and at 32 and 64 px, on light and dark. Each glyph is scaled to about 78% of the tile width. Names ending `a` are the earlier proportions enlarged; names ending `b` are tighter compositions. `r1a r1b`: red recording dot then sound bars. `r5a r5b`: red dot then a wave that flattens into a line. `h3sa h3sb`: one stroke, a wave settling into a looping word. `j3sa j3sb`: sound curves thinning into handwriting. `j1a j1b`: two sound curves, then a scribble. The dot is `#ff4d4d` with a white ring so it keeps 3:1 contrast against the tile; colours stay in the icon SVGs. They are candidates only; none is shipped. Regenerate the icon set from one with `node scripts/make-icons.mjs j1b` (or any other name above).
