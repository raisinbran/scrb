# Scribe icon concepts

The shipped icon is `r1ai` (red recording dot and sound bars, white tile), the owner's choice of default. The older three concepts (`bubble`, `wave`, `nib`) stay here, and `node scripts/make-icons.mjs [name]` regenerates the icon set from any design. Open `preview.html` to compare the three concepts.

Four designs, each with an inverted version, are in `scribe-<name>.svg` (each with a `-win` version); `preview-all-options.html` and `preview-all-P.png` show them at large size and at 32 and 64 px, on light and dark. Each glyph is about 78% of the tile width. `r1a`: red recording dot then sound bars. `r5c`: red dot then a smooth voice waveform fading into a line. `h3sb`: one stroke, a wave settling into a loop. `h3sd`: a swelling voice wave ending in a small loop. Names ending `i` are inverted: white tile, indigo glyph. Owner decision (2026-11-14): `r1ai` is the only shipped icon. There is no Settings icon picker for now; it will be revisited after M1. The other designs (`r1a`, `r5c`, `r5ci`, `h3sb`, `h3sbi`, `h3sd`, `h3sdi`, and their `-win` versions) are reserve candidates kept here. The unfinished picker handoff (the contract field it needs) is in the closed PR #244, branch `cuc/icon-selector-handoff`, file `docs/handoffs/2026-11-14-app-icon-setting-contract.md`. The dot is `#ff4d4d` with a white ring (indigo on the inverted tiles) so it keeps 3:1 contrast; colours stay in the icon SVGs. Regenerate the icon set from one with `node scripts/make-icons.mjs r1ai` (or any other name above).
