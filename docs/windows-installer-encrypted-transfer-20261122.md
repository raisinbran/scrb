Status: **SOURCE CANDIDATE ONLY; NOT APPROVED FOR DISPATCH OR MERGE.**

The existing producer retains seven pinned-source/native-tool checks, signed MSVC runtime evidence, DLL/license closure and NSIS packaging. It emits six independently protected job outputs: manifest_sha256, source_commit, provenance_sha256, dependency_audit_sha256, producer_run_id and producer_run_attempt. This branch replaces public plaintext transfer with one ciphertext-only, run/attempt-scoped Actions artifact retained for one day. CODEOWNERS is not enforcement by itself. The existing GreatFirewall ruleset (27257173) protects deletions/non-fast-forward only, includes a role bypass and does not currently protect workflow edits. Single-owner GitHub self-review limitations must be handled honestly.

Runtime dispatch checks demand owner actor and triggering actor, exact repository and workflow-ref on main, first attempt, both explicit opt-ins and correct job identity. Consumer rejects absent/oversized ciphertext, missing/wrong key, bad ZIP metadata, non-files, unsafe/nested/duplicate/case-colliding paths, oversized entries, excessive compression, unexpected files, and failed protected hashes/source/run checks before any installer invocation. The existing independent candidate verifier and disposable standard-user install/uninstall checks are retained. Temporary plaintext and identity-file cleanup is attempted on success and failure; this is not a secure-erasure guarantee.
